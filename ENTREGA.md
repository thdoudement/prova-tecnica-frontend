# Guia de Entrega — Frontend

Projeto complementar ao backend. Documento completo da entrega: **[ENTREGA.md no repositório backend](https://github.com/thdoudement/prova-tecnica-backend/blob/main/ENTREGA.md)**.

## Repositório

https://github.com/thdoudement/prova-tecnica-frontend

## Execução rápida

```powershell
npm install
copy .env.example .env
npm run dev
```

Requer backend em http://localhost:3333 para o CRUD de notícias.
